# KORDIA Outdoor Furniture — 2026 site

Static bilingual (EN / 简体中文) site for **Foshan KORDIA Furniture** (佛山柯帝亚家具),
an outdoor furniture manufacturer selling to export and project buyers.

No build step and no dependencies — open `index.html`, or serve the folder:

```bash
python -m http.server 8000
```

## Layout

```
index.html              markup for all nine screens
assets/styles.css       design system + responsive + Chinese typography rules
assets/app.js           routing, i18n, filtering, selection, RFQ wizard
assets/catalog-data.js  341 products, generated — do not hand-edit
assets/images/          catalog (987 variants), hero, material tiles, logos
```

`assets/catalog-data.js` and everything under `assets/images/catalog` are generated by
`scripts/build-images.py` in the working project from the extracted catalog images.
Re-run that script rather than editing either by hand.

## How it works

Screens are hash-routed (`#/home`, `#/c/<collection>`, `#/s/<category>`, `#/p/<id>`,
`#/inquiry`, `#/factory`, `#/materials`, `#/shipping`, `#/contact`), so browser
back/forward behave normally and any view can be linked to directly.

There is no checkout. Every call to action composes a pre-filled WhatsApp message to
Fianna (+86 134 5084 6180) in whichever language is active. The selection drawer and the
four-step RFQ wizard both persist to `localStorage`.

## Images

341 catalog photographs across 6 collections and 22 categories. Source resolution is not
uniform — 253 originals are 1069×695, but 52 are 502px and 36 are only 340px wide (the
9-up accessory pages). Each image therefore gets its own size ladder capped at **2× its
own native width**, so nothing is upscaled into mush, and `srcset`/`sizes` let the browser
pick per slot. A product card at 291 CSS px pulls a 400px file of roughly 27 KB.

## Chinese

`app.js` sets `<html lang="zh-CN">`, and `styles.css` keys its Chinese overrides off that.
This matters: the Latin type is deliberately tight (Fraunces takes −0.02em and sub-1.0
line-heights well), and those same values collide when applied to full-width Han glyphs.
Fraunces has no Han coverage either, so the Chinese display face falls to PingFang SC /
Microsoft YaHei rather than a serif that exists on only one platform.

## Before launch

Placeholders are marked in the UI rather than invented, and need real values from Fianna:

- Factory figures shown as `[__]` — area, lines, staff, certifications, MOQ, lead times
- Copy marked `[confirm …]` / `[verify]` — alloy and rope spec, ports and Incoterms, export history
- Three slots labelled "Photography needed" — factory floor, showroom/gate, and a map embed
- Product names are derived from category + catalog reference. The printed catalog carries
  WNM-8xxx model numbers, but its pages have no text layer, so they could not be extracted.

## Image rights

Product photography originates from the supplier's printed catalog, which is branded
**WENS / 维妮美** — a different company from KORDIA. Permission to publish this photography
under KORDIA branding was still unconfirmed when this site was built. Resolve that before
the site is promoted publicly.
