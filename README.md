# KORDIA Outdoor Furniture — 2026 catalogue + 2027 collection

Static bilingual (EN / 简体中文) site for **Foshan KORDIA Furniture** (佛山柯帝亚家具),
an outdoor furniture manufacturer selling to export and project buyers.

The production site is published from the root of `main` by GitHub Pages at
https://kordiafurniture.com/. The `CNAME` file must remain in the repository root.

No build step and no dependencies are required. Open `index.html`, or serve the folder:

```bash
python -m http.server 8000
```

## Local factory-page review

Open `factory-preview.html` directly, or visit `/factory-preview.html` on the local
server. It opens the factory route and supports the same English/Chinese switch
and navigation as the site. Keep it alongside `assets/` when reviewing locally.
Regenerate the preview with `python scripts/build-factory-preview.py` after editing
`index.html`. Rebuild the factory photography with
`python scripts/build-factory-images.py`; add `--check` to validate its outputs.
The factory redesign has been approved for publication. `factory-preview.html` is
generated for local review and excluded from Git; production uses `index.html`.

## Layout

```
index.html              markup for all nine screens
assets/styles.css       design system + responsive + Chinese typography rules
assets/app.js           routing, i18n, filtering, selection, RFQ wizard
assets/garden-review.js scroll-linked homepage choreography
assets/panel-motion.js  pointer-responsive content panels
assets/catalog-data.js  402 products, generated — do not hand-edit
assets/images/          catalogue, garden, factory, material and brand imagery
catalog/                reviewed source manifests for the generated catalogue
scripts/build-catalog.py deterministic catalogue and 2027 image builder
```

`assets/catalog-data.js` and everything under `assets/images/catalog-2027` are generated by
`scripts/build-catalog.py` from `catalog/base-catalog.json`, `catalog/kordia-2027.json`,
and the internally archived source PDF at `../Correspondence/20261003/KORDIA-2027.pdf`.
Re-run the builder rather than editing generated output by hand. Use
`python scripts/build-catalog.py --check` during verification.

The reviewed client originals received on 24 October 2026 are mapped in
`catalog/original-images.json`, with source SHA-256 checksums and native dimensions.
To rebuild them from the client's `维妮美图片` folder:

```bash
python scripts/build-original-images.py /path/to/维妮美图片
python scripts/build-catalog.py --refresh-originals
python scripts/build-original-images.py /path/to/维妮美图片 --check
python scripts/build-catalog.py --refresh-originals --check
```

`--refresh-originals` preserves the published 2027 import without requiring its
archived PDF. A full catalogue rebuild also applies the original-photo manifest.
Photo matching uses the existing image composition: 42 supplier filenames differ
from the site's existing model codes. These discrepancies are recorded in the
manifest; model codes and specifications have been preserved for supplier review.

## How it works

Screens are hash-routed (`#/home`, `#/c/<collection>`, `#/s/<category>`, `#/p/<id>`,
`#/inquiry`, `#/factory`, `#/materials`, `#/shipping`, `#/contact`), so browser
back/forward behave normally and any view can be linked to directly.

There is no checkout. Every call to action composes a pre-filled WhatsApp message to
Fianna (+86 136030102587) in whichever language is active. The selection drawer and the
four-step RFQ wizard both persist to `localStorage`.

The homepage combines a layered garden opening, a navy factory overview, a scroll-linked
collection journey, materials, settings and projects. Motion can be paused, respects the
system reduced-motion preference, and falls back to a stable layout on smaller screens.

## Images

402 product cards across 6 collections and 24 categories. All 341 established catalogue
photographs now use the client-supplied originals, exported as quality-92 WebP at
400px, 800px and native width where those sizes fit within the source. Portrait and
smaller originals retain their full composition and native dimensions. There is no
upscaling, colour enhancement, sharpening or cropping. Content-hashed filenames
ensure browsers fetch the replacement photos; legacy exports remain available
for rollback. Collection covers and product detail views use the same replacements.
The 61 additions cover eight named 2027 series. Their catalogue cards and detail-page
hero images use the matching colour-faithful lifestyle renderings extracted directly from
the PDF; a contained product cutout remains available as an inset and alternate product
view for precise identification. Scenes are mapped by product type and exported in 440,
880, and 1196px responsive sizes without saturation or tone enhancement. Cutouts retain
their uncropped 400 and 800px variants.

The 2027 import records 66 pictured items as 61 canonical products after consolidating the
shared `0003311` dining table and `0003331` side table. The PDF prints `0009501` for both a
Free Form barstool and bar cart; these remain separate site products and are flagged for
supplier verification.

## Chinese

`app.js` sets `<html lang="zh-CN">`, and `styles.css` keys its Chinese overrides off that.
This matters: the Latin type is deliberately tight (Fraunces takes −0.02em and sub-1.0
line-heights well), and those same values collide when applied to full-width Han glyphs.
Fraunces has no Han coverage either, so the Chinese display face falls to PingFang SC /
Microsoft YaHei rather than a serif that exists on only one platform.
